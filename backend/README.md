# ⚙️ Módulo Backend & API (Rede Mega 12)

Este módulo conterá os serviços de banco de dados, sincronização em nuvem e persistência centralizada para múltiplos usuários (Compradores, Gerentes e Separadores de Galpão).

## 🗄️ Entidades Mapeadas:
- `OrderHeader` (Cabeçalho do Pedido, Fornecedor, Condição, Datas, Descontos)
- `OrderItem` (Produtos, Preço Compra, PDV Alvo, Custo Real Efetivo, Grade de Separação)
- `FiscalConfig` (Parâmetros Fiscais da Rede)
- `StoreConfig` (20 Lojas, Clusters A, B e C, Pesos Padrões)
